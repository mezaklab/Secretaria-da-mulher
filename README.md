# 🏛️ Secretaria Municipal da Mulher - Canindé de São Francisco

Landing Page institucional e Painel Administrativo para divulgação de ações, saúde, direitos e agenda oficial no município de Canindé de São Francisco/SE.

## 🚀 Funcionalidades
* **Portal Público (`index.html`)**: Apresentação institucional, galeria de eventos e canais de apoio.
* **Painel Administrativo (`admin.html`)**: Gerenciamento de cards, projetos e agenda com persistência via `localStorage`.

## 🛠️ Tecnologias
* HTML5 / CSS3
* Tailwind CSS
* JavaScript (Vanilla)
* LocalStorage API
